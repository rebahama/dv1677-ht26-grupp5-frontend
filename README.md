## Kör lokalt

1. git clone <https://github.com/rebahama/dv1677-ht26-grupp5-frontend>
2. cd  projekt foldern


## Installera dependencies 

1. npm install
Detta installerar följande:

* React
* React Router DOM
* Bootstrap
* React Bootstrap
* Vite 

## Starta serven

1. För att starta projektet skriv in npm run dev när du står i projektfoldern.

## Tekniker
Projektet är byggd med:
* React: 19.2.8
* React Router Dom: 7.18.4
* Bootstrap: 5.3.8
* React Bootstrap: 2.10.10
* Vite: 8.3.0
